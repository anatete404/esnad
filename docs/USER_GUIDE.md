# دليل المستخدم - منصة مؤسسة حسن حسن علي

## 🎯 نظرة عامة

منصة إلكترونية متكاملة لتقديم ومتابعة طلبات تقنين أوضاع الأراضي.

## 👤 للمواطن

### 1. إنشاء حساب

1. افتح الصفحة الرئيسية
2. اضغط "حساب جديد"
3. أدخل: الاسم الرباعي، الرقم القومي (14 رقم)، الهاتف، كلمة السر
4. اضغط "إنشاء الحساب"

### 2. تقديم طلب تقنين

1. من لوحة التحكم → اضغط "تقديم طلب جديد"
2. **الخطوة 1 (بيانات الأرض)**: المحافظة، المركز، المساحة (فدان/قيراط/سهم)
3. **الخطوة 2 (تفاصيل إضافية)**: تاريخ وضع اليد، السبب، النشاط، مصدر المياه
4. **الخطوة 3 (رفع المستندات)**: بطاقة الرقم القومي، التوكيل، إثبات وضع اليد، إلخ
5. **الخطوة 4 (المراجعة)**: راجع البيانات → اضغط "إنهاء والإرسال"

### 3. متابعة الطلب

**طريقتين:**
- **برقم التتبع** (من أي مكان بدون تسجيل): /track
- **من لوحة التحكم** ("ملفاتي")

### 4. الإشعارات

كل ما يحدث على طلبك، هتشوف إشعار في الجرس 🔔

## 👨‍💼 للموظف

### 1. تسجيل الدخول

افتح: `your-domain.com/portal/login`
أدخل: البريد وكلمة السر (من مدير النظام)

### 2. لوحة التحكم

- إحصائيات فورية
- أحدث الطلبات
- توزيع المراحل

### 3. إدارة الطلبات

- **الطلبات**: جدول كل الطلبات
- **بحث**: برقم التتبع / الاسم / الرقم القومي / المحافظة
- **فلترة**: حسب المرحلة أو الحالة

### 4. العمليات على الطلب

افتح أي طلب → هتلاقي:

**أ) نقل المرحلة:**
- اختر المرحلة الجديدة
- اكتب ملاحظات (اختياري)
- اضغط "تحديث المرحلة"

**ب) اعتماد المستندات:**
- راجع كل مستند
- اضغط "اعتماد" أو "إلغاء"

**ج) الإسناد:**
- اختر موظف من القائمة
- اضغط "إسناد"

### 5. إدارة المستخدمين (للأدمن)

- إضافة موظف جديد (الاسم، البريد، كلمة السر، الدور، الفرع)
- تعديل بيانات موظف
- تعطيل/تفعيل
- حذف (لو مفيش طلبات مسندة له)

### 6. التقارير

- مؤشرات الأداء (KPIs)
- توزيع المراحل
- آخر 6 أشهر
- أعلى الموظفين إنتاجية

### 7. سجل التدقيق

كل إجراء في النظام بيتسجل. تقدر تفلتر حسب:
- نوع الإجراء
- الكيان (طلب، مستند، موظف، مواطن)

## 🔒 الأمان

- **كلمات السر**: مشفرة bcrypt (12 rounds)
- **الجلسات**: JWT في httpOnly cookies
- **حماية المسارات**: middleware
- **الصلاحيات**: RBAC (11 دور، 21 صلاحية)
- **سجل تدقيق**: كل إجراء مسجل
