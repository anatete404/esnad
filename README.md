# منصة إسناد للتنمية الزراعية - تقنين أراضي الدولة

منصة متكاملة لتقديم ومتابعة طلبات تقنين أوضاع الأراضي.

## 🚀 المميزات

- **بوابة المواطن**: تسجيل، تقديم طلب، رفع مستندات، متابعة برقم التتبع
- **بوابة الموظفين**: لوحة تحكم، إدارة الطلبات، نقل المراحل، الإسناد، اعتماد المستندات
- **إدارة المستخدمين**: إضافة/تعديل/تعطيل الموظفين حسب الدور
- **سجل التدقيق**: تسجيل كل إجراء في النظام
- **التقارير**: مؤشرات أداء حقيقية من قاعدة البيانات
- **الإشعارات**: تنبيهات فورية للمواطن والموظف

## 🛠️ التقنيات

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4
- Prisma + SQLite (قابل للترقية لـ PostgreSQL)
- JWT للمصادقة (jose)
- bcryptjs للتشفير
- RBAC: 11 دور، 21 صلاحية

## 📦 التشغيل المحلي

### المتطلبات
- Node.js 20+
- npm 10+

### الخطوات

```bash
# 1) تثبيت المكتبات
npm install

# 2) تهيئة الداتابيز
npx prisma migrate dev

# 3) زراعة البيانات الأولية
npx prisma db seed

# 4) تشغيل السيرفر
npm run dev
```

افتح http://localhost:3000

## 🐳 التشغيل بـ Docker

```bash
# 1) نسخ ملف المتغيرات
cp .env.example .env
# عدّل JWT_SECRET في .env

# 2) البناء والتشغيل
docker compose up -d

# 3) متابعة السجلات
docker compose logs -f
```

## 📂 هيكل المشروع

```
app/                    - صفحات وواجهات
├── api/                - واجهات API
├── portal/             - بوابة الموظفين
├── dashboard/          - لوحة المواطن
├── apply/              - استمارة التقديم
└── track/              - متابعة الطلب

lib/                    - أدوات مساعدة
├── auth.ts             - المصادقة
├── rbac.ts             - الصلاحيات

└── audit.ts            - سجل التدقيق
```
